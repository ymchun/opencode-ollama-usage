# @ymchun/opencode-ollama-usage

An opencode TUI plugin for Ollama usage information.

## Install

```
opencode plugin add @ymchun/opencode-ollama-usage
```

## Config

Add the plugin to your `tui.json`:

```json
{
  "plugin": ["@ymchun/opencode-ollama-usage"]
}
```

## Development

```bash
bun install
bun run build
bun test
```
